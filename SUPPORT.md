# Support

Orderly Free Beta is currently focused on public testing.

Use the in-app feedback form for short messages:

- Bug
- Something confusing
- Feature idea
- Other

The feedback form is intentionally limited to a short message. It does not attach logs, ZIP files, file names, folder paths, profile details, or diagnostics.

For downloads and updates, use:

https://github.com/kenolabs11-sys/orderly/releases
