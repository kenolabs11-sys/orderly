# Orderly

Orderly is a local-first desktop app for organizing folders safely. It lets you preview what will happen before files move, run the cleanup when you are ready, and undo supported runs from local history.

This repository is the public download and update channel for Orderly Free Beta.

## Download

Download the latest release from:

https://github.com/kenolabs11-sys/orderly/releases

Current public focus:

- Windows: Free Beta installer
- macOS: planned DMG release
- Linux: planned package release

## What Orderly does

Orderly helps clean folders such as Downloads, Desktop, media dumps, and working folders by grouping files into clear destination categories.

Free Beta includes:

- Preview before organizing
- Run cleanup after review
- Undo supported runs from local history
- Profiles for different folders or workflows
- Watch mode
- Auto-apply for one profile
- Five built-in categories: Images, Videos, Audio, Documents, Archives
- Short in-app feedback for beta testing
- Manual update check through GitHub Releases

## Privacy

Orderly is designed as a local-first tool. File organization happens on the user’s machine.

The Free Beta feedback form sends only:

- selected feedback type
- written message

It does not attach logs, ZIP files, folder paths, file names, profile details, or diagnostics.

## Updates

Orderly checks a public update manifest and opens GitHub Releases for downloads. Silent installation is not used.

See `updates/update.json` for the current public update metadata.
